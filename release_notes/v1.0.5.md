# Release Notes

## Fixed Issues

Fixed missing passthrough for kwargs for load_mysql_db and load_sqlite_db.  To enable SSL with mysql, ssl_ca, ssl_cert, and ssl_key can be passed as additional kwargs to load_mysql_db.  These parameters will be passed to pymysql.
