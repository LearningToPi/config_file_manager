# Release Notes

## What's New

Added .json() function to ConfigList and ConfigDict. This allows easy conversion for json parsing or dumping to a json string.  Usage instructions:

    >>> config = ConfigDict({'test1': 1})
    >>> config.json()
    {'test1': 1}

    --- Either ---
    >>> json.dumps(config.json())
    '{"test1": 1}'
    --- Or ---
    >>> config.json(stringify=True)
    '{"test1": 1}'


## Fixed Issues

Use the example above to dump as a string rather than sending your config file directly to json.dumps(...).  Sending to json.dumps(...) will result in a "object not serializable" error.
