# Release Notes

## What's New

Added helper functions for creating or opening SQLite3 databases or connecting to MYSQL.

    from config_file_manager import load_file, load_sqlite3_db, load_mysql_db, generate_encryption_key

    # load a JSON or YAML file.  Supports encryption and save on update (values are written to the source file as soon as they are updated)
    config_from_file = load_file(filename='test.json', encryption_key_file='encrypt.key', save_on_change=True)
    
    # open or create a SQLite3 database.  Supportts encryption.  Save on update is automatic.
    config_from_sqlite3 = load_sqlite3_db(filename='test_db.sqlite3', encryption_key_file='encrypt.key')

    # open a MYSQL DB.  Supports encryption. Save on update is automatic.
    config_from_mysql = load_mysql_db(host='server1', user='test_user', password='password1', database='schema1', table='kv', encryption_key_file='encrypt.key')

    # Create a new encryption key, saved as the file specified (if provided, file is not required).  Key is returned whether a filename is provided or not.
    key = generate_encryption_key(filename='encrypt.key')
